## 1. 登录模块

### 1.1 功能概述

用户通过用户名和密码登录系统，登录成功后才能访问系统内所有页面。未登录用户访问任何页面时，自动跳转到登录页。

### 1.2 用户操作

| 操作         | 说明                                   |
| ------------ | -------------------------------------- |
| 登录         | 输入用户名和密码，点击"登录"提交       |
| 退出登录     | 点击右上角"退出登录"，清除登录状态     |
| 记住密码     | 可选勾选"记住密码"，关闭浏览器后保留用户名和密码（本地存储） |

### 1.3 业务规则

- 用户名和密码为必填项，任一为空时提示"请输入用户名"或"请输入密码"
- 用户名或密码错误时，提示"用户名或密码错误"，不清空已输入的用户名
- 连续输错 5 次后，该账号锁定 30 分钟
- 登录成功后，服务端创建会话（Session / Token），前端保存登录凭据
- 登录成功后跳转到仪表盘首页

### 1.4 特殊情况

| 场景             | 处理方式                                       |
| ---------------- | ---------------------------------------------- |
| 账号被锁定       | 提示"账号已被锁定，请30分钟后重试"             |
| 未登录直接访问   | 前端路由守卫检测，跳转到登录页                 |
| 会话过期         | 操作时后端返回未登录状态码，前端清除凭据并跳转登录页 |
| 多人同时登录同一账号 | 允许，不做互踢处理（v1.0 简化）            |

## 2. 仪表盘

### 2.1 功能概述

登录后的首页，以可视化图表方式展示教学数据的整体概况，帮助管理者快速了解当前状态。

### 2.2 展示内容

#### 统计数字卡片（4 张）

| 卡片名称       | 数据说明                                   |
| -------------- | ------------------------------------------ |
| 学生总数       | 系统内当前未删除的学生总数                 |
| 班级总数       | 系统内当前未删除的班级总数                 |
| 今日出勤率     | 今日出勤人数 ÷ 应到人数 × 100%，保留一位小数 |
| 待批改作业数   | 已提交但尚未批改的作业总数                 |

#### 图表

| 图表                 | 类型     | 说明                                           |
| -------------------- | -------- | ---------------------------------------------- |
| 各班级学生人数分布图 | 柱状图   | X 轴为班级名称，Y 轴为学生人数，从高到低排列   |
| 近 7 天出勤趋势图    | 折线图   | X 轴为日期（最近 7 天），Y 轴为出勤率，单位 %  |

### 1.3 业务规则

- 仪表盘数据为**只读展示**，不可编辑
- 今日出勤率 =（出勤人数 + 迟到人数）÷ 班级总人数 × 100%
- 待批改作业数 = 作业状态为"已提交"的作业数量
- 近 7 天指含今天的最近 7 个自然日
- 数据为实时查询，每次进入页面重新加载

### 1.4 特殊情况

| 场景                   | 处理方式                           |
| ---------------------- | ---------------------------------- |
| 没有任何班级/学生      | 卡片显示 0，图表显示"暂无数据"     |
| 今天还没有考勤记录     | 今日出勤率显示 0%                  |
| 某天无考勤记录         | 折线图中该天显示为 0% 或断开不连接 |

## 3. 学生管理

### 3.1 功能概述

对系统内所有学生信息进行统一管理，支持增删改查、搜索、筛选和分页。

### 3.2 用户操作

| 操作       | 说明                                                   |
| ---------- | ------------------------------------------------------ |
| 查询列表   | 进入页面默认加载学生列表，按创建时间倒序排列，支持翻页 |
| 按姓名搜索 | 输入框键入学生姓名（支持模糊匹配），回车或点击搜索     |
| 按班级筛选 | 下拉选择框选择班级，列表只显示该班级的学生             |
| 新增学生   | 点击"新增"按钮，弹出表单填写学生信息                   |
| 编辑学生   | 点击行尾"编辑"按钮，弹出表单回填已有数据               |
| 删除学生   | 点击行尾"删除"按钮，二次确认后删除                     |
| 翻页       | 底部分页组件切换页码，每页默认 10 条                   |

### 3.3 学生信息字段

| 字段名   | 类型   | 必填 | 说明                     |
| -------- | ------ | ---- | ------------------------ |
| 姓名     | 文本   | 是   | 2-20 个字符              |
| 学号     | 文本   | 是   | 唯一，格式由学校自定义   |
| 性别     | 单选   | 是   | 男 / 女                  |
| 联系电话 | 文本   | 否   | 11 位手机号              |
| 所属班级 | 下拉   | 是   | 从已有班级中选一个       |
| 入学日期 | 日期   | 是   | 不能晚于当前日期         |

### 3.4 业务规则

- 学号全局唯一，新增/编辑时做唯一性校验
- 一个学生只能属于一个班级
- 删除学生使用逻辑删除（`is_deleted = 1`），不在界面显示
- 姓名支持模糊搜索（`LIKE %keyword%`）
- 班级筛选和姓名搜索可以组合使用
- 支持翻页，默认每页 10 条，可选 10 / 20 / 50

### 3.5 特殊情况

| 场景                     | 处理方式                                       |
| ------------------------ | ---------------------------------------------- |
| 学号已存在               | 新增/编辑时提示"该学号已被使用，请更换"        |
| 删除学生时该生有成绩记录 | 允许删除学生，成绩记录保留但学生字段显示"已删除" |
| 删除学生时该生有待批作业 | 允许删除，待批作业标记为"已失效"               |
| 班级没有学生             | 班级下拉仍可选，列表为空即可                   |
| 搜索无结果               | 显示"暂无数据"                                 |

## 4. 班级管理

### 4.1 功能概述

管理系统内的班级信息，每个班级指定一名负责老师，支持增删改查。

### 4.2 用户操作

| 操作       | 说明                                           |
| ---------- | ---------------------------------------------- |
| 查询列表   | 进入页面加载班级列表，按创建时间倒序           |
| 新增班级   | 点击"新增"，填写班级信息并指定负责老师         |
| 编辑班级   | 点击"编辑"，修改班级名称或更换负责老师         |
| 删除班级   | 点击"删除"，二次确认后删除                     |
| 搜索       | 按班级名称模糊搜索                             |

### 4.3 班级信息字段

| 字段名   | 类型   | 必填 | 说明             |
| -------- | ------ | ---- | ---------------- |
| 班级名称 | 文本   | 是   | 2-30 个字符，不可重复 |
| 负责老师 | 文本   | 是   | 2-20 个字符      |
| 班级描述 | 文本   | 否   | 最多 200 个字符  |

### 4.4 业务规则

- 班级名称全局唯一
- 每个班级指定一名负责老师
- 删除班级前检查该班级下是否有学生
- 班级下有学生时，不允许删除

### 4.5 特殊情况

| 场景                         | 处理方式                                           |
| ---------------------------- | -------------------------------------------------- |
| 班级名称已存在               | 提示"该班级名称已存在，请更换"                     |
| 删除班级时班级下有学生       | 提示"该班级下还有 XX 名学生，请先将学生转出后再删除"，阻止删除 |
| 负责老师修改                 | 不影响已有排课和考勤数据，仅更新班级记录           |
| 班级被删除后学生的班级归属   | 因班级下有学生时不允许删除，此场景不存在           |

## 5. 课程排课

### 5.1 功能概述

为各班级安排每周课程表，以表格形式直观展示一周课程安排（上午/下午、星期一到星期五）。

### 5.2 用户操作

| 操作         | 说明                                             |
| ------------ | ------------------------------------------------ |
| 查看课表     | 选择班级，以表格形式展示该班级的每周课表         |
| 添加课程     | 点击课表空白格子，填写课程名称、任课老师、时间   |
| 编辑课程     | 点击已有课程，修改课程信息                       |
| 删除课程     | 点击课程，可删除该课                             |
| 切换班级     | 下拉选择不同班级查看其课表                       |

### 5.3 课程信息字段

| 字段名   | 类型   | 必填 | 说明                         |
| -------- | ------ | ---- | ---------------------------- |
| 班级     | 下拉   | 是   | 选择排课班级                 |
| 课程名称 | 文本   | 是   | 如"语文""数学""英语"        |
| 任课老师 | 文本   | 是   | 2-20 个字符                  |
| 星期     | 下拉   | 是   | 周一至周五                   |
| 时间段   | 下拉   | 是   | 上午第一节 / 上午第二节 / 下午第一节 / 下午第二节 |
| 上课地点 | 文本   | 否   | 如"101教室"                  |

### 5.4 业务规则

- 同一班级 + 同一时间段（星期 + 时间段）只能安排一门课程
- 课程表按星期一至星期五、上午/下午的时间段展示
- 一个时间段只能有一门课

### 5.5 特殊情况

| 场景                           | 处理方式                               |
| ------------------------------ | -------------------------------------- |
| 同一时间段重复排课             | 提示"该时间段已有课程，请选择其他时间段" |
| 班级被删除后课表               | 因班级下有学生时不允许删除，此场景不存在 |
| 课程名称为空                   | 提交时校验，提示"请输入课程名称"       |

## 6. 考勤打卡

### 6.1 功能概述

记录和查看学生每天的出勤情况，支持四种考勤状态，按日期和班级查看。

### 6.2 用户操作

| 操作           | 说明                                               |
| -------------- | -------------------------------------------------- |
| 查看考勤记录   | 选择班级和日期，以表格列出该班当天所有学生的考勤状态 |
| 批量录入考勤   | 默认全部学生为"出勤"，逐人修改状态后统一保存       |
| 单个修改状态   | 点击某个学生的状态标签，切换为其他状态             |
| 按日期查看     | 日期选择器切换日期，查看不同日期的考勤             |
| 按班级查看     | 下拉框切换班级                                     |
| 出勤统计       | 班级页面顶部显示：应到人数、实到人数、出勤率       |

### 6.3 考勤状态

| 状态   | 说明                         |
| ------ | ---------------------------- |
| 出勤   | 正常到校上课（默认状态）     |
| 迟到   | 上课后到校，算入出勤率       |
| 请假   | 提前请假，不计入出勤率       |
| 缺勤   | 未到且未请假，不计入出勤率   |

### 6.4 业务规则

- 每天每个学生只需记录一次考勤
- 进入考勤页面时，当天考勤默认全员"出勤"，老师只需修改异常状态
- 同一天同一学生不能重复录入考勤
- 已保存的考勤可以修改（如学生补假条后从"缺勤"改为"请假"）
- 出勤率 =（出勤人数 + 迟到人数）÷ 班级总人数 × 100%

### 6.5 特殊情况

| 场景                         | 处理方式                                         |
| ---------------------------- | ------------------------------------------------ |
| 班级没有学生                 | 表格为空，显示"该班级暂无学生"                   |
| 当天考勤已录入后再次进入     | 加载已保存的考勤记录，可以修改                   |
| 节假日/周末                  | 不做考勤（日历组件中周末/节假日不显示为该日应有考勤，或允许跳过） |
| 学生转班后历史考勤           | 保留在原班级的考勤记录中，不受影响               |

## 7. 成绩管理

### 7.1 功能概述

老师录入和管理学生的各科考试成绩，支持按学生或按班级查看成绩，便于追踪学业表现。

### 7.2 用户操作

| 操作           | 说明                                               |
| -------------- | -------------------------------------------------- |
| 录入成绩       | 选择班级和考试科目，录入该班所有学生的成绩         |
| 编辑成绩       | 修改已录入的成绩                                   |
| 按学生查询     | 输入学生姓名或学号，查看该生所有科目的成绩记录     |
| 按班级查询     | 选择班级和科目，列表展示该班所有学生的该科成绩     |
| 成绩统计       | 显示平均分、最高分、最低分、及格率                 |

### 7.3 成绩信息字段

| 字段名   | 类型     | 必填 | 说明                         |
| -------- | -------- | ---- | ---------------------------- |
| 学生     | 关联     | 是   | 选择学生                     |
| 科目     | 文本     | 是   | 如"语文""数学""英语"        |
| 成绩     | 数值     | 是   | 0-100 分，支持一位小数       |
| 考试日期 | 日期     | 是   | 不能晚于当前日期             |
| 考试类型 | 下拉     | 是   | 期中考试 / 期末考试 / 月考 / 单元测试 / 其他 |
| 备注     | 文本     | 否   | 最多 100 字                  |

### 7.4 业务规则

- 成绩范围 0-100 分，超出范围提示"成绩应在 0-100 之间"
- 同一学生 + 同一科目 + 同一考试日期 + 同一考试类型为同一条记录，不允许重复录入
- 录入成绩时的学生列表为所选班级下的所有在读学生
- 平均分、最高分、最低分在查询结果底部展示

### 7.5 特殊情况

| 场景                 | 处理方式                                   |
| -------------------- | ------------------------------------------ |
| 成绩超出范围         | 前端校验 + 后端校验，提示"成绩应在 0-100 之间" |
| 重复录入             | 提示"该学生此科目的成绩已存在，是否覆盖"   |
| 班级无学生           | 录入表单的学生列表为空，提示"该班级暂无学生" |
| 学生被删除后历史成绩 | 保留成绩记录，学生姓名字段显示"已删除"     |

## 8. 作业管理

### 8.1 功能概述

老师在线发布作业，学生提交作业后老师可在线批改和打分，学生可查看自己的作业和批改结果（v1.0 仅做老师端管理功能）。

### 8.2 用户操作

| 操作         | 说明                                                 |
| ------------ | ---------------------------------------------------- |
| 发布作业     | 选择班级，填写作业内容、截止时间后发布               |
| 查看作业列表 | 按班级查看已发布的作业列表                           |
| 查看提交情况 | 点击某次作业，查看该班学生的提交状态（已提交 / 未提交） |
| 批改作业     | 对已提交的作业进行评分和写评语                       |
| 删除作业     | 删除已发布但无人提交的作业                           |

### 8.3 作业信息字段

| 字段名     | 类型   | 必填 | 说明                         |
| ---------- | ------ | ---- | ---------------------------- |
| 班级       | 下拉   | 是   | 发布到哪个班级               |
| 作业标题   | 文本   | 是   | 2-50 个字符                  |
| 作业内容   | 文本   | 是   | 10-1000 个字符               |
| 截止时间   | 日期   | 是   | 不能早于当前时间             |
| 发布人     | 自动   | -    | 当前登录用户                 |

### 8.4 提交记录字段

| 字段名     | 类型   | 必填 | 说明                                 |
| ---------- | ------ | ---- | ------------------------------------ |
| 学生       | 关联   | 是   | 提交学生                             |
| 作业       | 关联   | 是   | 对应作业                             |
| 提交内容   | 文本   | 否   | 学生提交的内容（v1.0 简化，文本即可） |
| 提交时间   | 日期   | 自动 | 提交时自动记录                       |
| 提交状态   | 枚举   | 是   | 未提交 / 已提交 / 已批改             |
| 评分       | 数值   | 否   | 0-100 分，批改后填写                 |
| 评语       | 文本   | 否   | 最多 200 字                          |

### 8.5 业务规则

- 作业发布给整个班级，每个学生都需要提交
- 截止时间过后，学生不能再提交作业（标记为"逾期未交"）
- 每次作业的评分范围 0-100 分
- 已有人提交的作业不允许删除，但可以关闭（不再接收新提交）
- 批改后状态从"已提交"变为"已批改"

### 8.6 特殊情况

| 场景                     | 处理方式                                         |
| ------------------------ | ------------------------------------------------ |
| 提交截止时间早于当前时间 | 提示"截止时间不能早于当前时间"                   |
| 删除已有人提交的作业     | 提示"已有学生提交，无法删除，是否改为关闭该作业？" |
| 班级无学生               | 发布作业时提示"该班级暂无学生"                   |
| 学生被删除后作业记录     | 保留提交记录，学生字段显示"已删除"               |
| 评分超出范围             | 提示"评分应在 0-100 之间"                        |

## 附录 A：全局通用规则

| 规则         | 说明                                           |
| ------------ | ---------------------------------------------- |
| 登录验证     | 所有页面（除登录页外）需要登录后才能访问       |
| 数据删除     | 全部使用逻辑删除（`is_deleted`），不做物理删除 |
| 操作反馈     | 所有增删改操作完成后弹出操作结果提示（成功/失败） |
| 表单校验     | 前端提交前校验 + 后端接口校验，双重保障         |
| 分页         | 列表页面默认每页 10 条，支持 10/20/50 切换     |
| 异常处理     | 后端异常统一捕获，返回友好提示，前端不暴露技术细节 |
| 时间格式     | 日期格式统一为 `YYYY-MM-DD`，时间格式 `YYYY-MM-DD HH:mm:ss` |

## 附录 B：模块依赖关系

```
登录 → 仪表盘
        ├── 学生管理 ← 班级管理
        ├── 班级管理
        ├── 课程排课 → 班级管理
        ├── 考勤打卡 → 学生管理 + 班级管理
        ├── 成绩管理 → 学生管理 + 班级管理
        └── 作业管理 → 学生管理 + 班级管理
```

> 箭头表示"依赖"，如"考勤打卡"模块需要先有"学生管理"和"班级管理"的数据才能正常使用。
