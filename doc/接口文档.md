## 通用说明

### 统一返回格式

所有接口返回格式统一为：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 状态码说明

| code  | 含义           |
| ----- | -------------- |
| 200   | 操作成功       |
| 400   | 请求参数错误   |
| 401   | 未登录或会话过期 |
| 403   | 无权限         |
| 500   | 服务器内部错误 |

### 分页参数约定

列表查询接口，请求参数统一用 `page` 和 `pageSize`，返回统一用 `total` 和 `list`：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "list": []
  }
}
```

### 分页请求参数

| 参数名   | 类型    | 必填 | 位置     | 说明                 |
| -------- | ------- | ---- | -------- | -------------------- |
| page     | integer | 是   | Query    | 第几页，从 1 开始    |
| pageSize | integer | 是   | Query    | 每页条数，可选 10/20/50 |

## 一、登录模块

### 1.1 登录

| 项目     | 内容                           |
| -------- | ------------------------------ |
| 用途     | 用户通过用户名和密码登录系统   |
| 请求方式 | POST                           |
| 请求地址 | /api/login                     |

**请求参数**（请求体 JSON）

| 参数名   | 类型   | 必填 | 说明   |

```json
  "message": "success",

```

**失败返回**

```json
{
  "code": 400,
  "message": "用户名或密码错误",
  "data": null
}
```

