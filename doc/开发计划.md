## 阶段一：前端页面（全部使用假数据）

> 此阶段不依赖任何后端代码，所有数据在前端 mock 层中硬编码返回。目的是先把页面布局、交互逻辑、表单校验做完并可供演示。

---

### 任务 1：公共 CSS 样式 + Mock API 工具层

**任务内容：** 创建全局公共样式文件和前端 Mock API 工具层。Mock API 暴露 `window.API` 对象，内部用假数据模拟全部 36 个后端接口，每个方法返回 `Promise` 以模拟异步请求。公共 CSS 定义布局、侧边栏、顶栏、卡片、表格、表单等全局样式变量。

**涉及的文件：**

| 文件 | 说明 |
|------|------|
| front/css/common.css | 全局样式：CSS 变量（颜色/字号/间距）、侧边栏布局、顶部导航栏、卡片样式、表格样式、表单样式、按钮样式、响应式基础 |
| front/js/app.js | Mock API 对象 + 公共工具函数（getToken / setToken / clearToken / checkLogin / logout），提供 `window.API.login()` 等全部 36 个 mock 方法 |

**依赖：** 无（这是第一个任务）

| 验收点 | 验收项 |
|--------|--------|
| 1/4 | common.css 定义了侧边栏（宽度 220px）、顶栏（高度 56px）、主内容区、卡片的样式变量 |
| 2/4 | app.js 的 `window.API` 对象包含全部 36 个 mock 函数，每个返回 Promise + 模拟延时 300ms |
| 3/4 | mock 登录接口返回假 token，getToken/setToken/clearToken 基于 localStorage 正常工作 |
| 4/4 | checkLogin() 在无 token 时返回 false，有 token 时返回 true |

**验收标准：** 在浏览器控制台执行 `window.API.login({username:'admin',password:'123456'}).then(r => console.log(r))` 能输出假登录成功 JSON；执行 `window.API.student.list({page:1,pageSize:10})` 能输出假学生列表。
